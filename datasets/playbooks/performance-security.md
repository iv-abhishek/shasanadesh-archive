## How to answer
- GeM bid → GeM GTC 4.0 performance security clause (page 25) and, for UP departments, UP GeM GO dated 26.11.2024 para 44. Outside GeM → GFR 2017 Rule 171. Works contracts → the Works manual.
- Cover: when it is required (GeM: the order-value threshold in UP GO para 44), the percentage range, validity (GFR: beyond completion of all obligations including warranty), refund of bid security once performance security is received, and whether any category is exempt.
- UP: give the reduced rate from the 2021 UP GO (with its exception needing competent approval), and note the 2024 UP GeM GO says no category of unit is exempt from ePBG.

## Traps
- MSE/startup exemption applies to EMD, not to performance security, unless the page says so.
- Give the date and number of the UP order you rely on, since UP and central percentages differ.
